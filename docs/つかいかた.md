# つかいかた

## 0. 準備するもの

- `学傷補入力支援_v1.5.2.html`（配布されたファイル。数字は版なので、新しいものを渡されたら差し替えてください）
- パソコンと、Edge か Chrome

インストールは不要です。ファイルをダブルクリックすれば開きます。

> ファイルは自分の分かりやすい場所（デスクトップなど）に置いてください。
> 場所を移動しても設定は残りますが、念のため「7. 設定の保存・受け渡し」で
> ときどき JSON に書き出しておくと安心です。

画面には次の7つのセクションがあります。番号は画面の見出しと同じです。

1. あなたの情報
2. 申請者の情報
3. 団体の情報
4. メンバー辞書
5. 今回の活動
6. 作る
7. 設定の保存・受け渡し

---

## 1. 最初の1回だけやること

### 1-1. 自分の情報を入れる

画面の「1. あなたの情報」に、氏名・カナ氏名・学籍番号・メールアドレスを入れます。

> ここが空だと、名簿の作成もフォーム入力も使えません。
> 配られたファイルをそのまま使う場合も、ここだけは必ず自分で入れ直してください。
> 直さないと、配った人の名前で申請してしまいます。

カナ氏名は名簿に使うため、書き方が決まっています。

- 全角カタカナ
- 姓と名の間は全角スペース（例: `ワセダ　タロウ`）

学籍番号は半角英数8桁です。ハイフン以降は入れません（例: `1A123456`）。

### 1-2. 申請者の情報を入れる

「2. 申請者の情報」に、申請者の氏名とメールアドレスを入れます。申請者は本学教職員に限られます。

- 「共有用メールアドレス」は、自分のアドレスを使う場合はチェックを入れるだけで済みます。
- よく使う申請者は保存しておくと、次回からクリック1つで呼び出せます。

### 1-3. 団体の情報を入れる

「3. 団体の情報」に、団体名・活動名・責任者名・加入区分などを入れます。

> サークルの誰か1人がここを設定して、「7. 設定の保存・受け渡し」で
> 「団体配布用」として書き出したファイルを配れば、他の人は読み込むだけで済みます。
> 団体配布用のファイルには個人情報は入りません。

### 1-4. メンバーを登録する

「4. メンバー辞書」に、いつも参加する人の学籍番号とカナ氏名を登録します。

- 「1. あなたの情報」を入力すると、自分自身は自動で辞書に登録されます。
- 書き方が違うと、その人の行がオレンジ色になります。マウスを載せると理由が表示されます。
- ここも1人がまとめて登録して配れます（「7.」で「メンバー辞書のみ」を書き出します）。

---

## 2. 毎回やること

### 2-1. 参加者を選ぶ

「4. メンバー辞書」で、今回参加する人にチェックを入れます。
新しい人がいれば、その場で追加できます。

### 2-2. 活動の情報を入れる

「5. 今回の活動」に、活動内容・活動場所・活動開始日・活動終了日を入れます。

ここに入れた内容が、フォームと名簿の両方に使われます。
名簿の「申請年月日」には、今日の日付が自動で入ります。

> よく行う活動は「今の内容をプリセット保存」しておくと、次回から選ぶだけで済みます。

### 2-3. 名簿をダウンロードする

「6. 作る」の「名簿をダウンロード」を押します。

入力に足りないところがあると、作成前に一覧で表示されます。
名簿は `学傷補・学賠補 活動届用 参加者名簿.xlsx` というファイル名で保存されます。

Edge か Chrome では、あらかじめ「フォルダを選ぶ」で保存先フォルダを選んでおくと、
以後はそのフォルダに直接保存され、同名の古いファイルは自動的に `old/` フォルダへ退避されます。
フォルダを選んでいない場合は、ブラウザの通常のダウンロードとして保存されます。

> 大学配布のテンプレートをそのまま使って値だけを差し込んでいるため、
> 書式・入力規則・テーブルは元のまま残っています。中身を確認してから提出してください。

### 2-4. フォームを開く

「② フォームを開く」の青いリンクを押します。値が入った状態でフォームが開きます。

入る項目はリンクの下に一覧で表示されます。17問中15問が自動で埋まり、
残るのは参加者名簿の添付と送信ボタンだけです。

> このリンクにはあなたの氏名とメールアドレスが含まれます。他人に送らないでください。

送信する前に、必ずフォームの内容を目で確認してください。

### 2-5. うまく入らなかったとき（予備手段）

大学がフォームを変更すると、リンクだけでは入らなくなることがあります。
そのときは「③ 入らなかった項目を埋める」のブックマークレットを使います。

初回だけ、青いボタンをブックマークバーにドラッグして登録してください
（`Ctrl` + `Shift` + `B` でブックマークバーが表示されます）。

> 登録は最初の1回だけです。設定を変えても、大学がフォームを変えても、
> 登録し直しは不要です（値はリンク側で渡しているため）。

②で開いたフォームの上でこのブックマークをクリックすると、15問を埋め直します。
画面右上に「どの設問に何が入ったか」の一覧が表示されます。
[OK] が入力成功、[失敗] が失敗、[スキップ] は「値が未設定なので触っていない」です。

### 2-6. 名簿を添付して、送信する

手作業として残るのは次の2つだけです。

1. 参加者名簿の添付 — 2-3 で保存したファイルをアップロード欄で選ぶ
2. 送信ボタンを押す — これは意図的に自動化していません

送信する前に、必ずフォーム本体も目で確認してください。

> オレンジ色の警告が出たときは、フォームが変更されている可能性があります。
> 特に「設問数が違います」と出たら、そのまま送信せず配布元に連絡してください。

## 3. こまったとき

### 設定が消えた

ブラウザの閲覧データを消すと、一緒に消えることがあります。
「7. 設定の保存・受け渡し」で定期的に JSON に書き出しておいてください。

### ブックマークをクリックしても何も起きない

- 活動届のフォームのページで押していますか（他のページでは動きません）。
- フォームが完全に表示されてから押してください。
- ブックマークの URL が `javascript:` で始まっているか確認してください。
  ブラウザによっては貼り付け時に先頭が削られることがあります。

### 「設問が見つかりませんでした」と出る

大学がフォームの設問を変えた可能性があります。
配布元の人に連絡してください。「7.」の中にある「フォーム調査を実行」を使って、
出てきた内容を送ってもらえると復旧が早くなります。

### 名簿の Excel を開いたら status 列が F になっている

参加者のどれかの行で、必要な項目が空になっています。
学籍番号・カナ氏名・申請年月日・活動開始日・活動終了日・活動場所のどれかが抜けていないか確認してください。

### 参加者が50人を超える

このテンプレートは50人までです。超える分は Excel で行を追加し、
テーブルの範囲を広げる必要があります（テンプレート内の注意書きに従ってください）。

---

## 4. データの取り扱いについて

- 入力したデータはこのパソコンの中だけに保存されます。どこにも送信されません。
- 書き出した JSON ファイルと、生成した名簿 Excel には、参加者の学籍番号と氏名が入ります。
  誰に渡すかに注意してください。
- 使わなくなったら「この端末のデータを全部消す」でまとめて消せます。

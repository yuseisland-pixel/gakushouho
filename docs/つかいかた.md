# つかいかた

## 0. 準備するもの

- `学傷補入力支援_v1.5.0.html`（配布されたファイル。数字は版なので、新しいものを渡されたら差し替えてください）
- パソコンと、Edge か Chrome

インストールは要りません。ファイルをダブルクリックすれば開きます。

> ファイルは自分の分かりやすい場所（デスクトップなど）に置いてください。
> 場所を移動しても設定は残りますが、念のため「6. 設定の保存・受け渡し」で
> ときどき JSON に書き出しておくと安心です。

---

## 1. 最初の1回だけやること

### 1-1. 自分の情報を入れる

画面の **「1. あなたの情報」** に、氏名・カナ氏名・学籍番号・メールアドレスを入れます。

> ここが空だと、名簿の作成もフォーム入力も使えません。
> **配られたファイルをそのまま使っても、ここだけは必ず自分で入れ直してください。**
> ここを直さないと、配った人の名前で申請してしまいます。

カナ氏名は名簿に使うので、書き方が決まっています。

- 全角カタカナ
- 姓と名の間は**全角スペース**（例： `ワセダ　タロウ`）

学籍番号は半角英数8桁です。ハイフン以降は入れません（例： `1A123456`）。

### 1-2. 団体の情報を入れる

**「2. 団体の情報」** に、団体名・活動名・責任者名などを入れます。

> サークルの誰か1人がここを設定して、「6. 設定の保存・受け渡し」で
> **「団体配布用」** として書き出したファイルを配れば、他の人は読み込むだけで済みます。
> 団体配布用のファイルには個人情報は入りません。

### 1-3. メンバーを登録する

**「3. メンバー辞書」** に、いつも参加する人の学籍番号とカナ氏名を登録します。

- 「自分を追加」を押すと、1-1 で入れた自分の情報がそのまま登録されます。
- 書き方が違うと、その人の行がオレンジ色になります。マウスを載せると理由が出ます。
- ここも1人がまとめて登録して配れます（「6.」で「メンバー辞書のみ」を書き出す）。

---

## 2. 毎回やること

### 2-1. 参加者を選ぶ

**「3. メンバー辞書」** で、今回参加する人にチェックを入れます。
新しい人がいれば、その場で追加できます。

### 2-2. 活動の情報を入れる

**「4. 今回の活動」** に、活動内容・活動場所・活動開始日・活動終了日を入れます。

ここに入れた内容が、フォームと名簿の両方に使われます。
名簿の「申請年月日」は、今日の日付が自動で入ります。

> よくやる活動は「今の内容をプリセット保存」しておくと、次回から選ぶだけで済みます。

### 2-3. 名簿をダウンロードする

**「5. 作る」** の **「名簿をダウンロード」** を押します。

入力に足りないところがあると、押す前に一覧で教えてくれます。
ダウンロードフォルダに `参加者名簿_団体名_日付.xlsx` が保存されます。

> 大学配布のテンプレートをそのまま使って値だけ入れているので、
> 書式・入力規則・テーブルは元のまま残っています。中身を確認してから提出してください。

### 2-4. フォームを開く

**「② フォームを開く」の青いリンクを押すだけです。** 値が入った状態でフォームが開きます。

入る項目はリンクの下に一覧で出ています。15問が自動で埋まり、
残るのは**参加者名簿の添付**と**送信ボタン**だけです。

> 💡 このリンクにはあなたの氏名とメールアドレスが含まれます。他人に送らないでください。

**送信する前に、必ずフォームの内容を目で確認してください。**

### 2-4b. うまく入らなかったとき（保険）

大学がフォームを変更すると、②で入らなくなることがあります。
そのときは **「③ 入らなかった項目を埋める」** のブックマークレットを使います。

初回だけ、青いボタンを**ブックマークバーにドラッグ**して登録してください
（`Ctrl` + `Shift` + `B` でブックマークバーが出ます）。

> **登録は最初の1回だけです。** 設定を変えても、大学がフォームを変えても、
> 登録し直しは要りません（値はリンク側で渡しているため）。

②で開いたフォームの上でこのブックマークをクリックすると、15問を埋め直します。
画面右上に「**どの設問に何が入ったか**」の一覧が出ます。

### 2-5. 名簿を添付して、送信する

**フォームの17問のうち15問は自動で埋まります。** 手作業で残るのは2つだけです。

1. **参加者名簿の添付** — 2-3 でダウンロードしたファイルをアップロード欄で選ぶ
2. **送信ボタンを押す** — これは意図的に自動化していません

自動入力を実行すると、画面右上に**「どの設問に何が入ったか」の一覧**が出ます。
✅ が入力成功、✖ が失敗、— は「値が未設定なので触っていない」です。

**送信する前に、必ずフォーム本体も目で確認してください。**

> ⚠ オレンジ色の警告が出たときは、フォームが変更されている可能性があります。
> 特に「設問数が違います」と出たら、そのまま送信せず配布元に連絡してください。

## 3. こまったとき

### 設定が消えた

ブラウザの閲覧データを消すと、一緒に消えることがあります。
「6. 設定の保存・受け渡し」で定期的に JSON に書き出しておいてください。

### ブックマークをクリックしても何も起きない

- 活動届のフォームのページで押していますか？（他のページでは動きません）
- フォームが完全に表示されてから押してください。
- ブックマークの URL が `javascript:` で始まっているか確認してください。
  ブラウザによっては貼り付け時に先頭が削られることがあります。

### 「設問が見つかりませんでした」と出る

大学がフォームの設問を変えた可能性があります。
配布元の人に連絡してください。「6.」の中にある **「フォーム調査（開発者に送る用）」**
を実行して、出てきた内容を送ってもらえると復旧が早くなります。

### 名簿の Excel を開いたら status 列が F になっている

参加者のどれかの行で、必要な項目が空になっています。
学籍番号・カナ氏名・申請年月日・活動開始日・活動終了日・活動場所のどれかが抜けていないか確認してください。

### 参加者が50人を超える

このテンプレートは50人までです。超える分は Excel で行を追加し、
テーブルの範囲を広げる必要があります（テンプレート内の注意書きに従ってください）。

---

## 4. データの取り扱いについて

- 入力したデータは**このパソコンの中だけ**に保存されます。どこにも送信されません。
- 書き出した JSON ファイルと、生成した名簿 Excel には、**参加者の学籍番号と氏名**が入ります。
  誰に渡すかに気をつけてください。
- 使わなくなったら「この端末のデータを全部消す」でまとめて消せます。

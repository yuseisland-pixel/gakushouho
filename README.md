# 学傷補・学賠補 活動届 入力支援

サークルの活動ごとに出す「学傷補・学賠補 活動届」の申請を楽にするツールです。

毎回同じ内容を入れ直す手間と、参加者名簿 Excel の大量のコピペをなくします。

## ⬇️ ダウンロード

**[Releases ページ](https://github.com/yuseisland-pixel/gakushouho/releases)** から最新版をダウンロードしてください。

---

## 使う人へ

配布されているのは **`学傷補入力支援_v1.5.1.html` という1つのファイル** だけです（数字は版）。
インストールは要りません。**ダブルクリックで開いてください。**

くわしい手順は [docs/つかいかた.md](docs/つかいかた.md) にあります。

### 大事なこと

- **入力したデータはこのパソコンの中だけに残ります。** インターネットには何も送信しません。
- **自動入力したあとは、必ず自分の目で確認してから送信してください。** 保険の申請書なので、
  間違った内容のまま送ると困ったことになります。
- 名簿ファイルには参加者の学籍番号と氏名が入ります。提出したら、不要なファイルは消してください。

---

## できること

| | 内容 |
|---|---|
| 個人設定 | 氏名・メールなどを最初に1回だけ登録すれば、以後は入力不要 |
| 団体設定 | 団体名・責任者名・加入区分など、サークルで共通の項目。1人が設定して配れる |
| メンバー辞書 | 学籍番号とカナ氏名を登録しておけば、次回からチェックを入れるだけ |
| 活動情報 | 場所と日付を1回入れれば、フォームと名簿の両方に反映される |
| 名簿の自動生成 | 大学配布のテンプレートに値を差し込んだ Excel をダウンロード。申請年月日は当日が自動で入る |
| フォームの自動入力 | 「フォームを開く」リンク1つで15問が入った状態のフォームが開く |
| 設定の受け渡し | JSON で書き出し・読み込み。団体配布用は個人情報を含めずに書き出せる |

**フォームの17問中15問が自動で埋まります。**

### 毎回の手順

1. ツールで参加者を選び、活動情報を入れる
2. 「**名簿をダウンロード**」
3. 「**値を入れてフォームを開く**」← リンク1つ。入らなかった分は③のブックマークレットで埋める
4. 名簿を添付して送信

### まだ手作業で残ること

- **名簿ファイルのアップロード**（ダウンロードしたファイルをフォームの欄で選ぶ、の1操作）
- **送信ボタンを押すこと**（これは意図的に自動化していません）

保険としてブックマークレットも用意してある。**値を含まないので登録は一度きり**で、
設定を変えても大学がフォームを変えても登録し直しは不要（値はリンクの `#` で渡す）。

### 動かし方

```
node tools/build.mjs            # src/ を1枚の HTML に畳んで dist/ に出す
node tools/verify-lint.mjs      # 構文チェックでは見つからない書き間違いを探す
node tools/verify-roster.mjs    # 名簿生成が原本を壊していないかを検査
node tools/verify-bundle.mjs    # 配布物の構文・埋め込み・事前入力URL・CSP 適合を検査
node tools/verify-probe.mjs     # 調査ブックマークレットを模擬フォームで実際に走らせる
node tools/verify-filler.mjs    # フォーム記入エンジンを模擬フォームで実際に走らせる
node tools/verify-browser.mjs   # Edge ヘッドレスで実際に動かして検査
powershell -ExecutionPolicy Bypass -File tools\verify-excel.ps1
                                # 生成した名簿を Excel 本体で開いて検査
```

依存パッケージはありません。Node と（Excel 検証だけ）Excel が要ります。

### 事前入力（prefill）の書式 — 種別ごとに違う

**値の書き方が設問の種別で違う。** これを知らずに全部を裸のテキストで送っていたため、
長いあいだ「1〜3番しか入らない」原因を取り違えていた。

| 種別 | 書式 | 例（エンコード前） |
|---|---|---|
| 単一行/複数行テキスト | そのまま | `?rXXXX=山田太郎` |
| **選択肢（ラジオ・ドロップダウン）** | **ダブルクォートで囲む** | `?rXXXX="1.国内 Domestic"` |
| **日付** | **yyyy-MM-dd をダブルクォートで囲む** | `?rXXXX="2026-09-01"` |

出典: <https://qiita.com/Rinatamu/items/f583444932cc2382e6bb>

### フォームは段階表示（分岐）になっている

| 段階 | 見えている設問 | 開く条件 |
|---|---|---|
| 初期 | 1〜5 | — |
| 次 | 6, 7, 8 | 5番（活動の種類）に回答 |
| 次 | 〜16 | 8番（活動主管箇所名）に回答 |

**この2つが重なって「1〜3番しか入らない」が起きていた。**
テキストの1〜3番は書式が合っていたので入るが、4番（ラジオ）は引用符が無いので入らず、
5番も入らないので**分岐が開かず**、6番以降はそもそも画面に存在しなかった。
URL の長さも並び順も綴りも、最初から無関係だった。

模擬フォーム（`tools/mock-form.mjs`）はこの段階表示を再現している。
**再現していなかった時期の「15/15通った」という検証は無意味だった**ので、
実物の分かっている性質は必ず模擬に反映すること。経緯は
[docs/事前入力の調査.md](docs/事前入力の調査.md)。

### 過去の申請について

**旧ブックマークレットは誤った欄に入力していました。** 大学が9番の設問を後から追加したせいで、
責任者名が空・箇所名に誤った値・国内/海外が未選択、という状態で提出されていた可能性があります。
詳細は [docs/開発メモ.md](docs/開発メモ.md)。この版で修正済みです。

技術的な背景と調査結果は [docs/開発メモ.md](docs/開発メモ.md) にまとめてあります。
**保守するときは必ず先に読んでください。**

### 構成

```
src/
  index.html / style.css / app.js   画面
  core/zip.js                       xlsx(=zip)を壊さず組み直す
  core/roster-xlsx.js               名簿テンプレへの値の差し込み
  core/store.js                     設定・メンバー辞書の保存と受け渡し
  core/prefill.js                   事前入力 URL の組み立て
  core/bookmarklet-gen.js           設定入りブックマークレットの生成
  form/probe.js                     フォーム調査用ブックマークレット（v2・2段階）
  form/filler.js                    フォーム記入エンジン（設問IDで特定・読み戻し検証つき）
  form/form-map.json                設問と入力値の対応表（★フォームが変わったらここを直す）
  template/参加者名簿.xlsx          大学配布テンプレの原本（手で編集しない）
tools/
  build.mjs                         単一 HTML 化。版はここの VERSION で上げる
  mock-form.mjs                     実測データから Forms を模した HTML を作る
  fixtures/probe-*.json             フォームの実測結果（模擬フォームの生成元）
  verify-*.mjs / verify-excel.ps1   検証7本
dist/                               配布物
```

### 提出物について

**提出物は参加者名簿の Excel だけです**（2026-08-24 に依頼者へ確認済み）。
要望ログには「Word ファイルで提出」という記述がありますが、言い間違いでした。
Word 文書の生成は不要です。

### 注意

- `既存ブックマークレート.txt` と `要望ログ.txt` はリポジトリにコミットされていません（`.gitignore` で除外）。
- `src/template/参加者名簿.xlsx` は大学が配布しているため、著作権配慮から、
  初回起動時に Cloudinary（CDN）から取得する仕様に変更しました。
  リポジトリ公開時に著作権リスクはありません。

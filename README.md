# 学傷補・学賠補 活動届 入力支援

サークルの活動ごとに提出する「学傷補・学賠補 活動届」の申請を支援するツールです。
毎回同じ内容を入力し直す手間と、参加者名簿 Excel への大量のコピーアンドペーストをなくします。

## ダウンロード

[Releases ページ](https://github.com/yuseisland-pixel/gakushouho/releases) から最新版をダウンロードしてください。

## 利用者向けの案内

配布されているのは `学傷補入力支援_v1.5.2.html` という1つのファイルだけです（数字は版）。
インストールは不要で、ダブルクリックで開けます。詳しい手順は [docs/つかいかた.md](docs/つかいかた.md) を参照してください。

### 重要な注意

- 入力したデータはこのパソコンの中だけに保存されます。インターネットには何も送信しません。
- 自動入力のあとは、必ず自分の目で内容を確認してから送信してください。保険の申請書のため、誤った内容のまま送信すると重大な問題になります。
- 名簿ファイルには参加者の学籍番号と氏名が含まれます。提出後、不要になったファイルは削除してください。

### できること

| 機能 | 内容 |
|---|---|
| 個人設定 | 氏名・メールアドレスなどを最初に1回登録すれば、以後は入力不要 |
| 団体設定 | 団体名・責任者名・加入区分など、団体で共通の項目。1人が設定して配布できる |
| メンバー辞書 | 学籍番号とカナ氏名を登録しておけば、次回からチェックを入れるだけ |
| 活動情報 | 場所と日付を1回入力すれば、フォームと名簿の両方に反映される |
| 名簿の自動生成 | 大学配布のテンプレートに値を差し込んだ Excel を出力。申請年月日は当日の日付が自動で入る |
| フォームの自動入力 | 「フォームを開く」リンク1つで、17問中15問が入力済みのフォームが開く |
| 設定の受け渡し | JSON での書き出し・読み込み。団体配布用は個人情報を含めずに書き出せる |

### 毎回の手順

1. ツールで参加者を選び、活動情報を入力する
2. 「名簿をダウンロード」を押す
3. 「値を入れてフォームを開く」リンクを押す（入らなかった項目はブックマークレットで補える）
4. 名簿を添付して送信する

手作業として残るのは、名簿ファイルの添付と送信ボタンを押すことの2つだけです。送信は意図的に自動化していません。

予備としてブックマークレットも用意しています。ブックマークレット自体は値を含まないため登録は一度きりで、設定を変えてもフォームが変わっても登録し直しは不要です（値は「フォームを開く」リンク経由で渡します）。

## 開発・保守する人向けの案内

一般利用者は上記までで十分です。以下は開発・保守に関する詳細です。

### 動かし方

```
npm run build             # src/ を1枚の HTML に畳んで dist/ に出す
npm run verify:lint       # 構文チェックでは見つからない書き間違いを探す
npm run verify:roster     # 名簿生成が原本を壊していないかを検査
npm run verify:bundle     # 配布物の構文・埋め込み・事前入力 URL・CSP 適合を検査
npm run verify:choices    # form-map.json の選択肢文字列の正しさを検査
npm run verify:mock       # 模擬フォーム自体の妥当性を検査
npm run verify:probe      # 調査ブックマークレットを模擬フォームで実走
npm run verify:filler     # フォーム記入エンジンを模擬フォームで実走
npm run verify:browser    # Edge ヘッドレスで配布物を実際に動かして検査
powershell -ExecutionPolicy Bypass -File tools\verify-excel.ps1
                          # 生成した名簿を Excel 本体で開いて検査
```

依存パッケージはありません。Node.js と、Excel 検証にのみ Excel 本体が必要です。
CI（.github/workflows/verify.yml）ではビルドと verify スクリプト9本を実行します。

### 設計上の制約

事前入力（prefill）の値の書式は設問の種別ごとに異なります。

| 種別 | 書式 | 例（エンコード前） |
|---|---|---|
| 単一行/複数行テキスト | そのまま | `?rXXXX=山田太郎` |
| 選択肢（ラジオ・ドロップダウン） | ダブルクォートで囲む | `?rXXXX="1.国内 Domestic"` |
| 日付 | yyyy-MM-dd をダブルクォートで囲む | `?rXXXX="2026-09-01"` |

参考: <https://qiita.com/Rinatamu/items/f583444932cc2382e6bb>

選択肢はフォームが持つ文字列との完全一致が必要です。全角スペース（U+3000）や NBSP（U+00A0）を含めて1文字も違ってはいけません。正確な文字列は input 要素の value 属性にあり、調査ブックマークレット（probe v3）はそこから読み取ります。

フォームは段階表示（分岐）になっています。

| 段階 | 見えている設問 | 開く条件 |
|---|---|---|
| 初期 | 1〜5 | なし |
| 次 | 6〜8 | 5番（活動の種類）に回答 |
| 次 | 9番以降 | 8番（活動主管箇所名）に回答 |

このため、分岐を開く設問を事前入力から外してはいけません。また、URL が長すぎるとサインイン自体が AADSTS90015 で失敗するため、URL 長には上限を設けています。

模擬フォーム（tools/mock-form.mjs）はこの段階表示を再現しています。実物で判明した性質は必ず模擬フォームにも反映してください。調査の経緯は [docs/事前入力の調査.md](docs/事前入力の調査.md)、技術的な背景は [docs/開発メモ.md](docs/開発メモ.md) にまとめてあります。保守の際は先に読むことを推奨します。

### 構成

```
src/
  index.html / style.css / app.js   画面
  core/zip.js                       xlsx(=zip) を壊さず組み直す
  core/roster-xlsx.js               名簿テンプレートへの値の差し込み
  core/store.js                     設定・メンバー辞書の保存と受け渡し
  core/prefill.js                   事前入力 URL の組み立て
  core/bookmarklet-gen.js           ブックマークレットの生成
  core/save-target.js               保存先フォルダの管理（File System Access API）
  form/probe.js                     フォーム調査用ブックマークレット（v3）
  form/filler.js                    フォーム記入エンジン（設問IDで特定・読み戻し検証つき）
  form/readback.js                  読み取り専用ブックマークレット
  form/form-map.json                設問と入力値の対応表（フォームが変わったらここを直す）
tools/
  build.mjs                         単一 HTML 化。版はここの VERSION で上げる
  mock-form.mjs                     実測データから Forms を模した HTML を作る
  fixtures/probe-*.json             フォームの実測結果（模擬フォームの生成元）
  verify-*.mjs                      検証スクリプト9本
  verify-excel.ps1                  Excel 本体での検証
dist/                               配布物
```

### 配布物（dist/）の一覧

ビルド（`npm run build`）は次の4ファイルを生成します。いずれも配布して使うもので、作業用の一時ファイルではありません。

| ファイル | 役割 | 対象 |
|---|---|---|
| `学傷補入力支援_vX.html` | ツール本体。一般利用者にはこれだけを配布する | 利用者 |
| `フォーム調査ブックマークレット_probe-v3.txt` | フォームの設問構成（設問ID・見出し・種別）を読み取る。フォームが変更されたときの追従用。ドロップダウンは開かない | 保守 |
| `選択肢の採り直し_probe-v3.txt` | 選択肢の正確な文字列を input の value 属性から採り直す版。ドロップダウンを開閉するため、全設問が見えている状態で実行する | 保守 |
| `読み取りブックマークレット.txt` | フォームの現在の入力状態を読み取るだけの確認ツール。入力・選択・送信は一切しない | 保守 |

過去に存在した「4番テスト」ブックマークレット（事前入力の引用符の要否を実機判定する一時ツール）は、
引用符の有無どちらでも効くことが確定したため v1.5.2 で撤去しました。

### 提出物について

提出物は参加者名簿の Excel だけです（2026-08-24 に依頼者へ確認済み）。Word 文書の生成は不要です。

### 注意

- 名簿テンプレート（参加者名簿.xlsx）は大学が配布しているものであるため、リポジトリには含めず、初回起動時に Cloudinary（CDN）から取得します。
